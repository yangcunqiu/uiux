# 假想人

评估一个界面，最容易拿到、也最常被当证据用的材料是"我自己打开试了试，觉得挺好"。这条说它为什么通常不算数、一条评估证据怎样才算数，以及拿不到真用户时补救手段按成色怎么排。

名字来自一篇改版复盘对评审现象的描述：评审的人把自己代入用户靠想——想出来的那个"用户"叫假想人。

## 我们的理解

### 一、假想人是怎么骗过你的

把自己代入用户去评估，出错的不是态度（想代入是好的），是材料：把评审现场当成了使用环境——投影的距离、会议室的灯光、手边的设备，都不是实际使用的那一套；并且用初见的目光评判天天用的产品。原文引的研究说法是：越是努力去猜用户怎么想，越会把自己的偏好注进去，还更容易忽略与猜测相悖的证据（出处《设计的陷阱》，具体研究未核实）。靠想得到的只是虚假的同理心。

### 二、评估证据的三个坐标

本条的核心表述（讨论提出，不是引用来的模型）：

> 一条评估证据带三个坐标——**谁的**（目标用户还是你）、**哪的**（使用环境还是你的环境）、**什么阶段**（初见还是稳态）。

"我自己打开试了试，觉得挺好"三个坐标通常全错：是你、在你的环境、你的初见。三个坐标的用法是能落地问出来的：每一条评估结论都对它问一遍，答不上来的降级为"我的观察"，不写成"用户会……"。评估的输出是判断，判断的成色取决于材料的成色。

拿不到真用户时，补救按成色排（讨论整理的成色序，不是研究结论）：

1. **去问**：问目标用户，成色最高——原文自己也承认真实环境平时体验不到，问是第一选择；
2. **了解行业**：业务怎么运转、用户是干什么的；
3. **模拟环境**：把观看距离、设备、时长往使用环境靠；
4. **了解人的共性**：认知的普遍规律，比空想强，但换算到具体用户隔着两层；
5. **空想**：直接代入自己，三个坐标全错。

### 三、评估时检查前提，而不是套用原则

两个案例（同一篇复盘，样本 1，各支撑就近的结论）：

- **提取按钮**：按"原则"顶对齐表单配左对齐按钮，按钮埋没了——原则的前提（用户从上往下逐项填）在实际使用里不成立，居中反而清楚。原则编码的是典型条件；评估时先问这条原则的前提在不在场，条件不在，原则就不到场。
- **选项优先**：作者自省当时没想过原方案适合哪种业务就直接改了。先弄明白现状为什么长这样，再决定换不换——现状往往不是蠢，是某个你没看到的条件。

这两条合起来是假想人的反面操作：假想人是拿自己的认知冒充用户的认知；检查前提是去查用户的实际条件。

## 为什么这样判断

- 三个坐标是讨论提出的表述；它的可检验性在于每条证据都能被问出答案，不需要研究背书就能用。
- 原文引的研究（越是猜越注入偏好）出处未核实；方向与已知的偏差研究（虚假同感一类）一致；本条不依赖它成立。
- 补救排序是讨论整理的成色序，不是研究结论。
- "检查前提"的两个案例来自同一篇复盘，样本 1。

## 适用条件和取舍

- 三个坐标是过滤"伪证据"的下限，不是产出"好证据"的上限——过了三坐标的证据还要看样本量、任务代表性，那些不在本条范围。
- "去问"本身怎么问才不把答案问歪（引导性提问、说的和做的不一致），没有讨论，留空。
- 评估自己做的演示和练习页时，"谁的"这个坐标换不了人；结论照实降级为"我的观察"，不冒充用户判断。

## 例子

- 会议室评审：投影距离、灯光、首次打开的目光——没有一个等于使用环境，这场评审能产出的只有"评审者初见观察"。
- 天天用的 app 回想初见印象 vs 现在印象：这个观察口过了三坐标后只能得出"我"的结论，写下来时如实标。

## 和其他主题的关系

- [美即好用的边界](../美即好用的边界/README.md)：颜值污染打分，是假想人在感受侧的特例——污染发生在你打分那一刻；本条管的是更宽的证据成色。
- [感受与论据](../感受与论据/README.md)：本条的下一步——你的感受降级为「我的观察」，用户报告的感受是数据；感受要当论据，先翻译成可检验的形态。
- [改动的代价](../改动的代价/README.md)：稳态对稳态、错按集中在谷底段——是"什么阶段"坐标落到测量上的样子。
- 三条合成一套评估纪律：证据从哪来（假想人）、感受怎么污染（美即好用的边界）、证据怎么算（改动的代价）。

## 还没定

- 原文引的研究出处未核实；找到原始研究前，本条靠三个坐标的可观察性立住。
- "去问"的问法偏差没有讨论，留空。
- 样本量、任务代表性什么时候进场，没有展开。
