# 布局变化与动效衔接

状态变化可能推动别的内容。先看移动本身需要传达什么，再决定消除位移、直接切换、用运动说明关系，或限制受影响范围。共用的控件确实是同一个对象时，可以移出变化区。只是外观相似却有独立状态时，合并会造成新的错误。预留常见内容的高度可以减少跳动，但会占用空闲空间。固定外框让变化留在内部，代价是可能出现裁切或内部滚动。

## 变化原因与阅读位置

小到难以察觉的位置差异有时可直接切换。这取决于内容与设备，不能预设统一的像素界线。用户直接打字导致输入框增长，原因与动作同时可见。切换标签页并立即替换整块内容时，替换区域内的几何变化通常也较容易解释。后台数据稍后到达、变化超出被替换的区域、或没有线索说明触发原因时，这一判断就不再成立。例如点标签只替换面板，却把正在阅读的页脚推离原位。可以预留空间、固定阅读位置或给出与更新同时出现的提示。

即使变化原因清楚，较大的位移仍可能让使用者丢失原来的阅读位置。需要追踪某行排序后去了哪里时，移动对应关系本身就是信息。此时过渡可以帮助追踪。连续输入区域则应让反馈紧跟输入，不宜在每次按键与布局响应之间插入等待。调整位置与直接插值尺寸的实现成本也不同，整体缩放可能使文字暂时变形。

局部替换能解释几何变化，不能自动说明筛选已重置、选择已清空等业务状态变化。切换标签时如有这类影响，需要单独体现。变化是否会被注意及位移多大才影响阅读，依赖内容和任务，没有统一感知阈值。

## 同一对象在两个阶段间的衔接

若入场末帧和拖动首帧声称呈现同一物体，应核对交接处的位置、大小、透明度，以及连续运动需要保留的速度。脚本结束时卡片在一处，用户一接手就跳到另一处，是可直接复现的不连续。物体完全移出画面或被完全遮挡时，可以在不可见处重置位置。半透明遮挡或边缘仍露出时，不能直接假定变化不可见。

卡片换层时，如果遮挡关系在仍重叠的可见区域内突然反转，会看到原先盖住的部分一下被盖回去。需要表现真实换位时，先移出将要跨越的卡片区域，再调整层级。若两个阶段本来就要表示不同对象或新页面，则可以有意切换。几何能否连续可直接检查，用户是否更偏好某种过渡仍需另行判断。
