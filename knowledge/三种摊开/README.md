# 三种摊开

折叠、分段、标签都是把「值」摊在版面上，只是摊的位置和档位不同：分段摊全部，折叠摊一段，标签摊的是「已选」。

## 先看演示

[折叠、分段、标签](折叠分段标签.html)（双击打开，不需要本地服务）

三块：

1. **折叠**：筛选面板的三段。切「单开 / 多开 / 多开 + 徽标 / 多开 + 摘要」，展开、勾选，注意下面「列表从这里开始」被推到了哪。
2. **分段**：同一组时间范围。切「宽容器 / 窄容器」，勾「去掉颜色」，看被裁掉的选项和选中态。
3. **标签**：十二个条件。切「换行 / 写 3 个 + N / 只写 3 个（不标）」，点 × 删一个；下面还有两种身份（回执 / 选项）。

观察重点：

1. 折叠切「单开」再点开第二段：第一段自己关上，同一时间只有一组在场；切「多开」，两组可以并排比较，代价是下面那行「列表从这里开始」被推得更远。
2. 「徽标」只告诉你有几项；「摘要」把名字写出来。收起时它们是回执，展开后自动让位——内容已经在眼前。
3. 分段切窄容器：右边的选项被裁掉，没有任何提示。它不是「藏」，是「以为全露其实没露」。
4. 去掉颜色再看分段：如果选中只靠颜色，灰度下就只剩一点深浅差；靠填充、边框和抬升才稳。
5. 标签切到「只写 3 个（不标）」：看起来只有 3 个条件，其实有 12 个。点 × 删一个，第四个会补上来——被藏起来的其实还在。
6. 下面两个身份：回执的 chip 是「删掉这个条件」，选项的 chip 是「选/不选这个值」。同一个外观，两种行为，别混在一个 chip 上。

## 我们的理解

**折叠。** 它和下拉的分工不在省空间，在**能不能让两组同时在场**：下拉一次只能开一个，折叠可以两段都开着。所以判据是「要不要并置」：要 → 折叠；不要 → 下拉。

- 代价是**布局位移**。下拉不推内容，折叠推；靠近视口底部的折叠段，展开后触发点可能被推出去。吸顶标题或「展开后滚回标题」能缓解。
- 单开省高度，多开才谈得上并置。按「要不要比较两组」选，不按「哪个更常见」选。
- 徽标是数量，摘要是内容，都是收起时的回执；必须在内容变化的那一刻同步，展开后让位。摘要截断会把「有内容」掉回「只有数量」，甚至变成「不标」——这是[藏起来的代价](../藏起来的代价/README.md)里那条级别跳档的另一种形态。

**分段。** 硬约束只有一条：**一行放得下**。放不下就换控件，别让它滚——溢出是静默的，从「全露」直接掉到「无痕」。演示里 9 个选项在窄容器里裁掉 2 个，没有任何提示；触摸端的滚动条默认也不显示。

- 分段和 Tab 长得像，语义不同：分段改的是值（列表变、位置不变），Tab 改的是位置（整块内容换）。
- 选中指示器要能脱离颜色成立（填充、边框、抬升），见[选中的表达](../选中的表达/README.md)。
- 多选不要用分段：分段天生互斥。

**标签。** 它有两种身份：

- **已选值的回执**（筛选条件、收件人）：每个 chip 是「删掉这个条件」。
- **可选项**（标签选择器）：每个 chip 是「选/不选这个值」。

别把两种行为混在同一个 chip 上。回执的 × 是行里的第二个目标：必须是真按钮，不能嵌在 label 里（否则点 × 会连选中一起切换），键盘要能单独到达——这是[选项行](../选项行/README.md)里那个坑的另一种形态。

标签的溢出有三档：换行（占高度）、+N（有数量没内容）、只写前几个不标（假回执）。只有前两个能用。

## 为什么这样判断

- 折叠是唯一能让两组同时在场的容器；位移是 in-flow 的代价。这是结构事实，不是偏好。
- 分段的溢出没有中间档：从全露直接到无痕，所以它比下拉更糟——下拉至少有个触发器。
- 标签摊的是「已选」，回答的是状态，不是集合；所以它天然是回执那一侧的工具。
- 三个控件的档位：分段 = 全露，折叠 = 一段，标签 = 已选的内容。它们不是在同一个问题上的三个答案，而是三种不同的摊法。

## 适用条件和取舍

- **折叠**：靠近底部注意位移；摘要要同步；嵌套折叠慎用（位移叠加）。
- **分段**：互斥、短标签、少选项；硬约束是放得下。放不下就换控件，别加滚动。
- **标签**：值少（3–5 个以内）才放触发器；溢出用 +N 或换行，不静默裁；自由输入省一次选择，换来脏数据（重复、错拼），要么给建议，要么做校验。
- 关联：选中指示器见[选中的表达](../选中的表达/README.md)；第二个目标见[选项行](../选项行/README.md)；控件语义（互斥/集合）见[承诺与边界](../承诺与边界/README.md)；留痕分级见[藏起来的代价](../藏起来的代价/README.md)；容器与拉取见[取回与放置](../取回与放置/README.md)。

## 例子

- **筛选面板三段**：多开比较，摘要显示已选；收起时徽标给数量。
- **时间范围分段**：9 个在窄容器里裁掉 2 个，没有提示。
- **收件人 chips**：回执，点 × 删除；标签选择器：选项，点击切换。
