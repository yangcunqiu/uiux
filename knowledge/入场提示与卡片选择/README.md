# 入场提示与卡片选择

首次出现的内容可以交代当前对象、接下来应看哪里，以及能对它做什么。每个入场阶段需要有具体作用，例如反映真实等待、说明空间关系、预示可操作方式、引入随后会响应的物体，或形成展示任务需要的氛围。没有真实生成过程时，模拟生成的文字会给出错误的等待信息。纯体验活动可以把揭示过程本身作为目的，高频工具则要考虑每次进入的成本。

注意顺序可以按“先辨认对象、再找到相关位置、最后接管操作”安排。每个阶段宜有可辨认的关注对象，装饰可与它同阶段出现而不争夺注意。若过程本身就是叙事内容，也可以先解释如何形成，再揭示结果。对象本身继续响应、入场与之后操作发生在相应位置、入场动作预示随后手势，都能建立联系。装饰物会响应不代表使用者能操纵它。检查入场结束后是否还有线索可辨认下一步，以及画面是否从最后一帧自然进入首次操作。删短入场、去掉说明、请人直接接手可以发现缺少的线索。一次顺利接手只说明这一次成功。

## 堆叠是否适合选择

堆叠能节省空间或提供逐张揭示的体验，也会遮住选项。任务是从多项中挑一项时，必须能在选定前辨认各对象。可同时扇开展示，也可逐张带到最前方。前者占空间以支持并行比较，后者节省空间但需要逐项浏览。如果选择是主要任务、空间足够且用户要对照多项，直接并列可能更合适。仅作浏览或通知数量提示时，辨认要求不同。

悬停某张卡使其移动，卡片移出指针后又立即收回，会使目标来回切换。这个问题取决于触发区域随卡片移动、展开与悬停互相触发、且状态没有保持。可以保留稳定的触发区域，收起时只覆盖可见卡片，展开后才扩展到整个可操作区。从卡片原先露出的方向展开有助于保持对应关系，幅度既要足以辨认，也要受可用空间限制。描边能说明指向哪张卡，本身不能代替被遮挡的名称。

指针路过就展开可以少点一次，也会误触发。周边拥挤、卡片并非主任务或使用触摸设备时，点击后展开有明确价值。换卡的滑动方向与卡边露出的方向可分别决定。当效果意在表现实体卡片换位，应先离开将跨过的重叠区域再交换前后层级。简单高频轮播可以选择直接、短促的切换，不必付出完整实体运动的时间。[布局变化与动效衔接](../布局变化与动效衔接/README.md)
