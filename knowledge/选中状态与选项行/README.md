# 选中状态与选项行

选择列表需要同时表达“哪一项已选”和“点击这一行会改变什么”。把键盘焦点、悬停、已选和不可用状态分别呈现。两种状态共用浅色底时，保留勾、点、轮廓或其他看得出的差别，使指针移入未选项后仍能辨认真实选择。

## 选中状态

勾或点有明确位置，小尺寸下需保持清晰。填充和轮廓的变化依赖前景与背景的对比，单靠边框加粗或字重变化时差别可能很小，还可能引起位移。检查静态画面，以及深色、强制颜色和减少动态效果时还剩哪些线索。移除色相是检查剩余线索的一种方法，无法代替对使用者的观察。

对采用《网页内容无障碍指南》（WCAG）2.2 的 Web 产品，1.4.1 要求避免用颜色作为传递信息的唯一视觉手段。1.4.11 的 3∶1 要求适用于识别界面组件及其状态所必需的视觉信息与相邻颜色，条款包含非活动组件等例外。[颜色的使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) · [非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

用户完成一次选择后，选择值按该控件的生效约定更新。动画可以说明方向，但不应把已接受的输入排成一串等待播放的状态。连续快速切换时，从当前位置转向最新值。减少动态效果时可以直接显示最终状态。勿把本地已经选中误写成服务端已经保存。

## 行内布局与第二个操作目标

文字为主的行，勾选框宜对齐名称首行。描述换行时，以整行居中会让标记远离名称。以图片为识别对象时，可以对齐图片中心，同时保留可读名称或替代说明。描述跟随文字列。影响选择的信息应直接可见，可有可无的补充说明才适合放进帮助入口。数量需要比较时可以单独成列，并说明它代表全部结果，还是加入当前选项后的结果。

让标签和主要内容都可用于选择。如果行尾另有帮助按钮或删除入口，点它只执行自己的动作。Web 中可将关联到复选框的 `label` 与独立按钮作为同级元素。把非交互图标直接放在标签内，点击它可能同时切换勾选。每个独立按钮都会增加一次键盘停留，触摸设备还需要点击即可读到的说明。

采用 WCAG 2.2 的 AA 符合等级时，指针操作目标通常至少为 24 × 24 CSS 像素。应结合间距、同行文字、等效控件等适用例外判断。AAA 等级的增强目标尺寸条款另设 44 × 44 CSS 像素要求，并有自己的例外。选项是否竖排则取决于标签长度、可用宽度和控件与名称的对应关系，长标签、翻译后变长时尤其要检查。[最小目标尺寸与例外](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) · [增强目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html)
