# 屏宽与缩放

屏幕变宽，页面不会等比放大；它只是拿到更多 CSS px，然后按规则重排。所以 1440 上看到的是更多内容，不是更大的内容。把"重排"当成"缩放"来设计，最后会得到 7.8px 的字。

## 先看演示

[打开「屏宽与缩放」](屏宽与缩放.html)（双击即可，不需要本地服务）

框里是一块模拟屏幕，宽度可切 800 / 1024 / 1280 / 1440；策略可切"重排"和"等比缩放"。同一个页面，两套做法。

观察重点：

1. 切到 800："重排"里字 14px、按钮 40px、弹窗 750px（占屏 94%）；"等比缩放"里字 7.8px、按钮 22px、弹窗 444px（占屏 56%）。
2. 切到 1440：两种做法完全一样——差别只在"屏幕宽度不等于设计宽度"时出现。
3. 框的高度也跟着变：缩放模式把整页缩到 56%，高度只剩一半多。

## 我们的理解

**CSS px 是布局里的绝对单位。** `width: 800px` 就是 800 个 CSS px。屏幕只决定"窗口有多少 CSS px 宽"；浏览器拿到这个宽度，按规则重新排版。整个过程里没有"整体缩放"这一步。

**浏览器自带的自适应只有两条**：文字在给定宽度里换行；装不下出滚动条。`max-width`、百分比、flex/grid、断点，都是作者写的规则。所以"现在的页面都自适应"是个误会——能自适应的页面，是因为有人写了那些规则。

**真的会缩放的五种情况**：

| 机制 | 视口 CSS px | 看起来 |
|---|---|---|
| 浏览器缩放（Ctrl +/−） | 变小（1440 屏 125% → 1152） | 全页放大 |
| 系统缩放（Windows 150%） | 变小（1920 屏 → 1280） | 字更清楚、更占地方 |
| 设备像素比 / 视网膜屏 | 不变 | 只是更清楚 |
| `transform: scale()` | 不变（布局按原尺寸占位） | 整体缩小或放大 |
| 手机捏合 | 布局视口不变 | 视觉放大 |

系统缩放常被当成"只改清晰度"。它同时改可用宽度：1920 屏设成 150%，浏览器看到的是 1280 个 CSS px。这就是 1024 今天仍然是真实下限的原因——不是老显示器，是别人把笔记本调到了 125%。

**为什么 web 不默认缩放。** 字和点击目标不能缩。1440 的设计缩到 800 屏是 0.56×，14px 变 7.8px、40px 的按钮变 22px。反过来，1440 的设计放到 2560 上就是 1.78×，字 25px，界面像老人机。所以选择是：容器变、内容重排；缩放权交给用户。

**为什么很多网站看起来像等比缩放。** 它们用 `max-width: 1200px; margin: 0 auto`。1440 屏上多出来的 240px 变成左右留白，看起来像"整体缩小居中"；其实字号没变，只是留白变多。

## 为什么这样判断

- "不是缩放"来自长度的取值方式：布局完成后长度就是像素值，视口变化触发的是重排，不是缩放。
- 两列数字是在演示里量的：字号取计算值乘缩放系数，按钮和弹窗用 `getBoundingClientRect` 读实际渲染尺寸。
- 五种机制的区别落在"视口 CSS px 变不变"这一列，可以直接验证；系统缩放的 1920 → 1280 是 1920 ÷ 1.5。
- "字不能缩"是取舍判断，不是测量结论。演示只说明缩了之后多大，没有证明人读不了。

## 适用条件和取舍

- **等比缩放在固定画幅的产品里成立**：大屏看板、H5 海报、游戏、信息亭。那边内容本身是一张画，缩放不破坏语义；代价是宽高比不同时会留黑边或裁切。
- **B 端后台不是画，是工具箱**：内容是表格、表单、选项，缩放会让字和点击目标一起变小。这类界面按宽度重排，不按比例缩放。
- 浏览器缩放、系统缩放、设备像素比的数值随浏览器和系统设置变化；文中的 1440×125%=1152、1920÷1.5=1280 是算术，不是实测。
- 演示里的"等比缩放"是模拟——把 1440 的页面整体缩放。真实产品要做这件事，通常用 `transform: scale()` 或按视口宽度算根字号（rem 方案）。

## 例子

- 1440 屏上的 `max-width: 1200` 容器：左右各 120px 留白，看起来像缩放，其实是重排。
- 1366 笔记本开到 125%：视口 1093；150%：911。同一台机器，两种"小屏"。
- 1920 屏开到 150%：视口 1280，字仍是 14px，只是每个 px 用了更多物理像素。

## 稳定性

| 内容 | 稳定性 | 写法 |
|---|---|---|
| CSS px 是绝对单位、屏宽触发重排 | 定义 | 写死 |
| 浏览器默认只做换行和滚动条 | 定义 | 写死 |
| 五种缩放机制的分类 | 定义 | 写死 |
| 视口 CSS px 的具体数值 | 经验值 | 随缩放设置变，写公式不写死数 |
| "B 端重排、H5 可缩放" | 判断 | 看内容是不是一张画 |

## 还没定
