备注

两点容易混的

  • 「屏幕变大」和「画面放大」是两件事。前者给页面更多 CSS px，后者是把同样的 px 画得更大。浏览器默认只做前者；后者要用户自己按 Ctrl +/−，或者你写 transform: scale()。
  • 系统缩放两头都动。1920 的屏设成 150%，浏览器看到的是 1280 个 CSS px（1920 ÷ 1.5）：字还是 14px，但可用宽度小了；同时每个 CSS px 用更多物理像素画，所以更清楚。它不是“整页缩小”，是“窗口变窄 + 变清晰”。这也是为什么 1024 在今天仍然是条真实的下限——不是老显示器，是别人把笔记本调到了 125%。
