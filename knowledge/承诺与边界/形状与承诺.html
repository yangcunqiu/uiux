形状承诺了什么

同一个设置——深色模式——四种做法。变的只有两件事：形状，和它什么时候生效。

先别看底部那行灰色小字。点几下，再「离开这个页面」，看哪一张的说法站得住。

深色模式的效果显示在 选后者时，演示读数一起藏起来，模拟真实界面。

看什么

  1. A 和 C 里，控制区和预览区永远同步：点完，两边说的是同一件事。
  2. B 和 D 里有一个时间差：控制区先变，预览不变。这个时间差本身不稀奇——B 的保存按钮在明说「还没提交」。
  3. D 的开关说的是「它现在开着」，而它没开。看得见预览时，你会说「这功能很怪」；把效果挪到另一个页面，你就只剩开关这一个说法——不在场的证据，才是「我以为已经开了」的来源。
  4. A 和 C 用「撤销」换掉「保存」：少一步确认，欠一个反悔窗口；撤销过期之后，没有第二次机会。
  5. 顺便看措辞：单选的标签是选项值（浅色 / 深色），开关的标签是功能名（深色模式）。前者在说「选哪个」，后者在说「这个开着」。

底部灰字是演示读数，真实界面里不会有。
