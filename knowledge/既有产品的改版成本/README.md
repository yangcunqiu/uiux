# 既有产品的改版成本

改版会改变用户已经学会的位置、路径、顺序或名称。评估成本要同时看受影响人数和每人依赖现有方式的程度。少数操作员每天长时间完成同一流程，也可能比大量偶尔访问者有更高的重新学习成本。人数和熟练程度是估计因素，没有可通用相乘的量化单位。

换颜色或字重主要影响重新辨认。移动入口会改变空间位置，改步骤和确认时点会改变动作序列，改变平台惯例还会影响从其他产品迁移来的经验。改菜单名也可能使培训材料、同事口头指引和客服话术失效。新增功能虽可保留旧路径，但增加入口也会带来查找成本。新版与用户已熟悉的外部惯例更接近时，旧产品的某些学习负担反而可以减少。

## 比较何时、如何测量

先记录旧版熟练阶段代表性任务的完成情况，再分别观察改版初期及重新熟练之后。可以测同一任务的完成用时、点向旧位置的次数占可比尝试的比例、恢复到原有水平需要多长时间。初期的下降和恢复后的差异回答不同问题。工单、培训提问和抱怨可以提供线索，难以单独区分使用频率、对新设计不满和旧习惯受影响。

长期收益还要结合任务发生频率、产品预计使用期和迁移成本。首次试用对美观的好评值得记录，高频任务是否更顺利则要观察真实操作。面向熟手的工具与一次性体验，投入重点可以不同。

## 迁移按任务安排

能切开时，按可以独立使用、验证和回退的任务分批迁移。同一任务的一半沿用旧顺序、另一半采用新规则，会迫使使用者不断切换。若不存在可正常工作的中间状态，或依赖旧习惯很少，整段一次切换可能更合适。保留旧入口能提供退路，也要维护两种行为，并使使用数据难解释。采用这种方案宜同时定义退出条件。为熟手给出“原功能现在在哪里”的映射，有时比要求重学整套教程更直接。
