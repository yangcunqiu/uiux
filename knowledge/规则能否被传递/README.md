# 规则能否被传递

把一条设计规范交给别人（开发者、AI、下一任设计），有时顺利、有时失败。这个主题谈的是分界线：**一条规范能不能跨过「墙」，等价于它能不能写成「输入 → 输出」的规则。** 写得出来的跨得过去；写不出来的，传递通道只剩案例和拟合参数，而那两条通道传出的是「像」，不是「懂」。

对比度是标准案例：背景色由广告主设定（输入不在你手里），规范不能是两张静态稿，必须是一条可执行的推导——「亮则黑字、暗则白字」，配亮度公式。

三段：

1. **输入漂移**：左边是值表形态（两套黑白静态稿，采样点只有黑底白底），右边是同一条规范写成函数、每次输入现场算。拖背景亮度滑块到中灰——值表没有规定中间地带，接手的人只能自己补；规则跟着算。顺带看红底蓝底：开发自己补的「RGB 均值」版在红底上选错字色。
2. **两条补法**：值表侧没有规则，开发只能自己补。RGB 均值版（常见）和亮度公式版（正确）都「传递」得很顺利——差别不在传递效率，在有没有人验证过。
3. **拟合资产**：别人调出来的参数（temperature、Prompt）看起来像资产。只改一件事：直接用，还是重拟合一次再用。没走重拟合通道，它复现的是别人的输出分布；走了，它才是你形成经验的一次迭代。

## 我们的理解

### 一、界画在规则的性质上，不画在人和人之间

「设计师出静态稿、判断归开发」不是认识论立场，是**传递成本的历史产物**：交接时代，设计师的判断只能以制品形式过墙，静态稿是判断的采样。按输入域分三种情况：

| 输入域 | 规则形态 | 归谁 |
|---|---|---|
| 封闭（背景就这几种） | 静态稿即完备规格 | 分工成立，推导是开发细节 |
| 开放 + 可推导（对比度） | 一条输入→输出函数 | 组织选择：Guidelines、CSS、代码、Prompt 都行——**可检验的资产谁持有都成立** |
| 开放 + 不可形式化（「像我们」、这张图裁哪里） | 决策只存在于现场 | 谁也拿不走：收窄输入域、把决策现场搬到位，或接受拟合近似＋误差预算 |

原文里那场争执（「你作为设计都不知道什么时候会出什么颜色，你的设计没有做完」）的实质是：输入域一开，静态稿退化为函数的采样点，函数本身没过墙，于是开发在墙那边重新发明了它——发明得对不对，两边都没机制发现。

### 二、三个算出来的事实（对比度案例）

1. **「亮则黑字、暗则白字」用 WCAG 亮度算是全覆盖的——但余量只有 0.08**。纯黑纯白二选一，最坏点在背景 L≈0.179（中灰），对比度 4.58，刚好压过 4.5。这条规则「总能达标」是真的，但极其勉强；没跑过输入域的人只会当它是常识。
2. **文字色一柔化，洞就开了**。#333 / #f5f5f5 的两套稿，背景亮度落在 (0.164, 0.324) 时两档都不达标（#777777、#808080 全在洞里）。静态稿永远不含中灰案例——设计师不会主动做一张灰底稿。
3. **开发自己补的近似规则会错**。用「RGB 均值 ≥128 判亮底」：纯红（均值 85）判成暗底选白字 → 4.00 不达标，黑字本来 5.25；纯蓝碰巧选对。**近似的规则不是更松的规则，是另一条规则**——错误不随机，集中在饱和红和中灰。

### 三、拟合资产：第三类的沉淀物，不是第四种东西

调出来的参数（temperature、Prompt、Guidelines 里非推导非案例的部分）不需要单独立一格：它是**别人经验的外化快照**，和调性是同一种东西，只是外化程度不同。快照上带着多少形成时的有效条件，决定它离「规则」多远：

| 档 | 例子 | 有效条件跟着来了吗 | 能当什么用 |
|---|---|---|---|
| 推导规则 | 亮暗分界 + 亮度公式 | 全部（条件在数学里） | 规格，照抄 |
| 经验规则 | 「350px 换设备重算」 | 部分，靠自曝限度 | 带条件的默认，可偏离 |
| 拟合参数 | 调出来的 temperature | 几乎没有——拟合分布在哪个模型、哪批任务上，写的人自己也说不全 | 素材＋起点，须重拟合 |
| 调性 | 「像我们」 | 零 | 只能现场传染 |

品味和拟合参数的关键差别：品味是**生成性的**——对新输入产出新判断，换模型它自己重新拟合；拟合参数是**冻结的**——产出别人的输出。所以：

- **直接用 = 模仿**。原文作者喂 10 个案例「即便强调发散它也要模仿」，是同一失败在案例通道上的版本；拿别人的 Prompt 直接跑自己的任务，是拟合分布在别人那边。
- **重拟合 = 你自己沉淀过程的一次迭代**。快照的价值只在这条通道兑现：拿来当起点，跑自己的输入，看结果，修。作者声称「Prompt 可以复用（即便模型不同）」，按此是一个可检验的预测分歧：他预测无损，本条预测跨模型部分失效——两边都没扫过。
- **折旧不同**：拟合参数按模型代际折旧，品味不折旧。
- **升格通道**：拟合参数补一次验证扫描（在什么任务、什么模型上测的），就从第三档升到第二档。带条件的形式是升格出来的，不是声明出来的。

**绝对不能写成无条件约束**的原因：无条件恰好是它最像规则、又最不是规则的地方——写成无条件，等于给快照伪造了它没带的条件。

### 四、验证责任：分工立场的真实事故

可推导的规则能传递，但**传递成功 ≠ 规则正确**。RGB 均值版传递得毫无损耗，错得也毫无损耗。可检验性只保证「谁都能验」，不保证「有人真的验了」。

「判断归开发」的真实事故不是判断过了墙，是**验证环节消失在墙的两侧之间**：设计师验不了（静态稿不含中灰案例），开发不觉得自己在做设计（只是实现），于是没人对输入域跑断言。反过来，「Prompt 是设计的一部分」那一侧也有同一个缺口：看起来可传递的资产，验证扫描缺位。

对输入域跑断言这件事，静态稿时代叫走查（下游比对），规则时代变成上游断言（把 0.179 那个点扫出来）。它不高贵，但三个数字都是它给的。

### 五、品味的形成论（讨论中认可的模型）

自己的品味怎么形成：天生之外，就是**看别人的分享、自己耗费时间迭代、真的接触做过、慢慢沉淀**。四个来源里「迭代」需要闭环才沉淀——选择 → 看见结果 → 修正；原文作者配的零件是录屏慢放（「『看见』并不是态度，而是能力」）。没有看见这一环，耗时磨出的是习惯，不是品味。

这个模型把拟合资产的位置也解释了：**别人的经验快照是形成品味的原料（「看别人的分享」那一项），不是品味的替代品。**

## 为什么这样判断

- 分界线（能写成输入→输出与否）对应[约束与调性](../约束与调性/README.md)在 J 簇的结论：约束可检验可照抄、调性只回答像谁。本条为它补了 AI 时代的独立证据：原文喂 10 个案例传「创新方向」得到模仿（负锚点）；Guidelines 声明语义和规则后一次还原成功（正锚点）。
- 三个对比度数字是算出来的，可复现（WCAG 相对亮度公式 + 4.5 门槛）；4.5:1 按工作区规矩只作「已发布的推导」用，不作主证据链。
- 拟合资产归第三类、形成论，来自本簇讨论（工作区所有者的模型），不是语料；标注为讨论结论。
- 「重拟合才兑现价值」「按代际折旧」是机制推论，无对照数据；升格通道没有实例验证。
- 「案例传染的是模仿不是懂」是对原文单一案例（N=1）的推广，靠形成论支撑，非实验结论。

## 适用条件和取舍

- 原文自己的逃生门依然有效：「除非你用真实的材料能做出更好、更完整的设计，否则你就不要碰」。本条没有推翻它，只是把「碰不碰」从个人选择改写为输入域性质决定：封闭域分工成立，开放且可推导的域归属是组织选择，不可形式化的域才轮到「别碰，除非」。
- 对比度案例是「开放且可推导」的最干净样本；多数颜色规范介于两者之间（部分可推导、部分调性），用本条时先拆开再套。
- 三个数字依赖 4.5 门槛的选取；换门槛，分界点数值变，**洞存在、近似规则会错**这两个结论不变。
- 演示第 3 段是文字对照不是可运行实验；「重拟合」没有真的跑模型。
- WCAG 亮度公式与门槛见 [WCAG 2.1 理解文档（Contrast Minimum）](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum.html)；原文出处《Figma Make 的使用建议与更多 AI 的思考》《使用 AI 制作交互动画的建议》（wxad，Aragakey.）。

## 稳定性

| 内容 | 稳定性 | 写法 |
|---|---|---|
| 能否传递 = 能否写成输入→输出 | 模型 | 写死，标注讨论结论 |
| 三分表（封闭／开放可推导／不可形式化） | 模型 | 写死 |
| 三个对比度数字 | 推导结果 | 写死（依赖 4.5 门槛，脚本可复现） |
| 快照四档表 | 模型 | 写死 |
| 直接用=模仿、重拟合=一次迭代 | 机制推论 | 写死，标注无对照 |
| 形成论 | 用户模型 | 标注为讨论认可的模型 |
| 「Prompt 可复用」之争 | 待检验 | 记为预测分歧 |
| 演示数值 | 演示值 | 不是推荐值 |

## 还没定

- 「Prompt 跨模型可复用」的预测分歧没有实际扫描过；两边都没测。
- 收窄输入域（限定模板）作为第三类出路，语料里没有对应案例，是推论。
- 拟合参数「按模型代际折旧」的速度没有数据——只说了方向没说量。
- 品味形成论中「天生」项不可检验，整条是模型不是数据。
- [走查的上游](../走查的上游/README.md)挂的验证项「提示约束的遵循率、条件误用率」：本条提供了定性证据（负锚点＋正锚点），量化仍然没有。
