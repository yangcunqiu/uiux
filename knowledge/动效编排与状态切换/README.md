# 动效编排与状态切换

运动可以表达层级、因果和分组。先确定用户需要分辨哪一种关系，再选择时序和对象。若动作的唯一结果是一段必须等完的装饰，高频使用会重复付出时间。

## 前后景、插入和删除

背景变暗、模糊或后退分别影响可读性、关注程度和空间感，须与背景能否操作相符。需要参照背景时，保留足够的可读性。必须先处理当前层时，清楚地呈现背景暂不可用。模糊因性能或平台能力而降级时，替代方式仍应维持相同的信息和操作关系。背景必须看得见时，完全不透明的替代背景会破坏任务。

列表插入一项时，可以先腾出位置再显示内容。删除时先让内容退出再收回空间。这样能表达谁导致谁。变化少、不需要追踪或两项互不相关时，可以立即切换或同时变化。新增项的静态标记还能帮助稍后回来的人定位。删除后对象已消失，需要核对的结果须由过程或其他结果提示承担。

同组元素依次入场可以同时体现整体与个体。每项的小延迟会随项数累积，最后一项太迟时会影响使用。固定时差表达先后出现。同一拖动输入下的不同跟随量则表达随输入传递的位移。在需要保持行距或卡片间距时，让每个元素不同步会使相对位置变形，可以让整组一起跟随。在工具型列表的反复滚动中持续让内容错位，成本每次都会发生。滚动叙事或低频展示可以有不同取舍。运动方向也有含义，例如返回原处适合表达取消，用不同方向区分确认和取消则需要重复使用、两种结果都会遇到、方向容易辨认且全产品一致。低频场合使用对称返回通常更可预期。减少动态效果时，结果和方向含义仍要可辨认。

## 哪些状态可以共享一个视觉对象

同组的悬停背景或选中指示器可以在若干目标之间移动。共享一个不带具体内容的背景兼有连续性和分组作用。把页码数字本身随指示器横移，则可能在途中短暂显示在错误的位置。仅在表示同一个对象切换状态时共享。增加和删除独立对象时，用户仍要能看出哪个对象出现或消失。共享范围由功能分组决定，响应式布局把按钮分进两个容器后，语义上的组未必改变。

相邻提示共用一次首次悬停的意图确认，可减少连续浏览时反复等待。关闭延迟可以让指针移入提示，但旧提示未消失、新提示已出现时会短暂遮挡。共用一个提示对象能保持切换连续，仍须给用户从入口移入内容的路径。

空间相撞时也可以临时合并表示。双滑块两端数值靠近，可以合成一个仍有意义的范围。不相关的说明不能按同样方式拼接。合并与分开的距离可以略有差别，避免临界点来回闪动。通知堆叠则保留多个对象，适合只需先知道数量、稍后可靠展开的低风险消息。必须阅读的错误若会从底部无声淘汰，应保留其他可回查入口。触屏不能只靠悬停展开。[入场提示与卡片选择](../入场提示与卡片选择/README.md)
