# 环形文字与渐变接合

有首尾的文字或色带放到圆周上，首尾相遇处需要明确处理。先确定对象用于识别图案，还是需要按顺序读完。再决定要保持字距、图形尺寸还是完全闭合。

## 沿圆周排字

等角度分配让每个字符占同样的角度，容易闭合。对于字宽相近的汉字或等宽文字，这种做法可能足够。混排窄字母、宽字母、标点和数字时，会出现不均匀的空白。按字体的前进宽度分配弧长可以保留部分原有字距节奏，但会剩下一段弧。按可见笔画的宽度排布能让几何间隙相等，也会改变字体原有的两侧留白。

装饰徽章可以牺牲字距换取整圆。品牌名、机构名等仍须辨认词形时，短词强行撑满整圈会散成独立字符。可将缺口与边框的开口对齐、用年份或起读标记占据空弧，或仅用一段弧。半径会影响整个构图，字号会影响层级，改文案则需要内容上的许可。标题、按钮、金额等要求快速顺读时，换成直排文本通常更合适。依赖测量字宽时，要使用实际加载的字体，回退字体的排布可能在加载后改变。

## 角向渐变的首尾

圆锥渐变中，圆周起点和终点相邻。若两侧最终颜色不同，会出现一条明显的边。需要连续时，给首尾安排相匹配的色值和色标，并核对色带的原有方向。例如将所有色标角度统一减去 δ，使首个色标回到零度时，渐变的起始角应加回 δ，才能保住画面中本应固定的颜色位置。用一条清楚的高光或指定色标做参照，可以同时检查“边消失了”和“光源还在原处”。有意留出硬边的转盘或分区图则无需抹平。[CSS 圆锥渐变](https://www.w3.org/TR/css-images-4/#conic-gradients)

将圆横向拉伸会同时拉伸其中的边框、文字和阴影。需要椭圆形且文字保持正常比例时，应分别处理背景和内容。旋转光源与旋转整个元素，在椭圆、文字或其他方向性内容存在时会有不同结果。
