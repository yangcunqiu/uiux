# 复盘的成色

什么样的复盘能教东西。判据不在成果的多少，在**弃案**——以及一个配套事实：自曝限度的语料，才能提炼出带条件的规则。

## 先看演示

无演示。判据本身可检验：拿一份复盘或一篇文章，数它的弃案密度——从中能学到多少「试了什么→为什么弃」。

## 我们的理解

### 一、能教学的复盘写弃案

成果清单（做成了什么）教不到边界——知道结果，不知道哪里不能去。**弃案＋弃由才可迁移**。

语料示例（同一作者的两篇复盘里，几乎每节一个弃案）：

- 文字与气泡的风格尝试全部被否，弃由是「修饰分散了对文字内容的注意力」；
- 确认页静态版双层失败：高亮抢按钮注意力＋气泡误导可点；
- 入场封面两版连弃：不表达「可揭开」／「分成两步没有必要」；
- 官网的「神奇移动」三条病（不表达关系、前后景不清、边缘切割感）催生容器放大；
- 编辑器三阶段（markdown → markdown＋模块 → 富文本）每一步都写了弃由；
- 动效规范先「明确要避免什么」，不是先画目标。

**检查法：弃案密度。**只有成果的复盘，弃案密度为零，学不到边界。

弃由分两档：

- **可观察型**（切割感、抢按钮注意力、误导可点、换行翻车）——可迁移；
- **直觉型**（「文字被扭曲的效果并不好，或者说是另一种感觉」）——只能当线索。

这是[感受与论据](../感受与论据/README.md)的翻译标准用在语料上：弃由要么翻译成可检验的形态，要么诚实标为立场。对后端背景的人：postmortem 里「为什么失败」比「做了什么」值钱是老直觉；新的部分是——**设计复盘拿不出指标，所以弃由必须是可观察的品质，这更难，也更挑语料**。

### 二、自曝限度是带条件规则的原料

- 无限度声明的语料 → 只能产出无条件规则——规则的适用条件是编的；
- **自曝限度的语料 → 产出带条件的规则。**

语料证据：

- 「现在看这样的优化其实也不是完全必要」→ 成本注记有了出处；
- 「对许多话题也只是浅尝辄止」→ 相关话题不写成定律；
- 2017 年的灾难清单（第 16 个视频崩掉 webview、先做小程序再换 H5、上线即 bug）→ 平台限制类知识有真实代价背书；
- 「没有太好地打磨和完成」→ 效果与结论分开记。

对 AI 规则提炼的扣环（本工作区的章程，见[走查的上游](../走查的上游/README.md)）：本簇每条沉淀都带稳定性表与「还没定」，原料正是这些自曝。**从只报喜的语料提炼规则，规则的条件就是编的。**换个说法：诚实不是美德问题，是**可提炼性**问题——限度声明是规则适用条件的唯一可靠来源。

## 为什么这样判断

- 弃案密度在语料上可数：成果展览型文章密度为零，与弃案型对照即得判据。
- 弃由两档的分法来自语料自身——同一作者两种弃由都有，可对照。
- 「限度 ⇒ 条件」是机制推论：条件只能来自原料里声明过的边界；原料无限度，条件只能外加，而外加的条件没有证据地位（[假想人](../假想人/README.md)定过：检查前提，不套用）。

## 适用条件和取舍

- 判据用在「选语料读」的时刻，也用在自己写复盘：写弃案和弃由，不只写成果。
- 直觉型弃由不是废料：它是后续观察的探测器，只是别当结论传。
- 限度声明不等于谦辞：要检查它是否真的指向边界（「浅尝辄止」→该话题降级）。谦辞式限度（「做得不好」但不说哪里不好）提炼价值低。

## 稳定性

| 内容 | 稳定性 | 写法 |
|---|---|---|
| 能教学的复盘写弃案；弃案密度检查法 | 方法 | 写死 |
| 弃由两档（可观察／直觉） | 判断 | 与感受与论据一致 |
| 限度声明 ⇒ 带条件的规则 | 机制推论 | 写死；对 AI 的效果待 P 簇验证 |
| 语料引文 | 案例 | 标注出处 |

## 还没定

- 弃案密度没有量化门槛（多少算高），是方向判据不是公式。
- 限度声明与谦辞的分辨没有展开：什么算真限度、什么算客套，需要例子对照。
