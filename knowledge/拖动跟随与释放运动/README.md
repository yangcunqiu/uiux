# 拖动跟随与释放运动

拖动期间先区分开始响应有多快、轨迹有多平滑、显示与输入相差多少。直接跟随指针能保持当前位置对应，也会呈现输入抖动。对持续输入做平滑可以减少小幅波动，代价是快速移动时显示更落后。每帧已开始响应却一直落在指针之后，与输入开始后过一段时间才有第一帧响应，是两种可分别检查的现象。输入本来就平稳、目标要求精确或使用键盘逐级调节时，这项收益较小。

精确滑块需要让使用者能以手柄位置和数值对准目标。拖动中将手柄置于会明显滞后的弹簧之后，会使人依据旧位置继续调整。既需要直观看到范围又需要精确输入时，可让滑块与数值输入框配合。对甩动卡片、翻页等较粗且可恢复的目标，允许一定偏差可以表达重量。松手时若仍落后，继续追到目标会用去额外时间，立即吸附会出现一次位置变化，在当前位置冻结则可能与实际输入终点不符。要判断哪一种符合该控件的输出。

在一个以弹簧自然周期 T 定义跟随时间、阻尼比为 1 的线性模型中，目标以恒速 v 移动并进入稳态后，位置落后量约为 vT/π。速度加倍时，采用同一参数的落后距离也加倍。这里 T 以秒计，不能把其他动画库中同名的“时长”直接代入。实际输入是否因此更好控制，需要在对应设备和任务上操作验证。

## 惯性、越界阻力与回弹

惯性是松手速度对后续目标或运动的影响。越界阻力是继续向边界外拉时，内容位移和手指位移的关系。回弹是松手后回到合法范围的过程。三者可以分别决定。无论是否启用惯性，直接操作中的后续运动应能被下一次输入从当前位置接管。按住和松手可以采用不同运动参数，但要衔接当时的位置和需要保留的速度。

触摸、目标较大、错误可恢复时，一次甩动能少拖一段距离。精确定位、容易过冲或后果严重时，宜优先保证即时定位。越界阻力适合需要让人感知内容边缘，或越界本身承担刷新等操作的场景。把普通到头做得像还能继续，可能诱导反复尝试。硬边界、惯性加硬边界、惯性加弹性边界都可自洽，取决于对象和输入方式。提供减少动态效果及适用的非拖动操作路径。

越界曲线的局部斜率表示手指移动一单位时内容跟随多少。随拉出距离逐渐减小跟随比例，可以形成越来越难拉的效果。固定比例只可能在部分区间逼近它，即使两条曲线的总拉出量相近。参数应说明数值增大时是更跟手还是更难拉，避免把跟随比例误当作阻力。例如越界距离 x、可视长度 d、初始跟随比例 c 均为正时，可用 y = dcx / (d + cx) 表示显示位移。局部跟随比例从 c 开始逐渐减小，y 在数学上趋近 d。只有操作能接近这个范围，理论上限才可能成为使用者实际感知的边界。

## 运动表现与经验阈值

若希望卡片随拖动速度倾斜，可用两个跟随同一输入但滞后不同的点，用两点的相对偏移产生倾角。两点同速同位时相对偏移为零。按物体自身尺度将差值换算为角度，会比给所有尺寸同一倾角更能表现同一几何关系。进入或重新接管时先对齐初始位置，避免首次移动突跳。更多不同滞后的点可以形成拖尾，也增加运动量。

用屏幕物理尺寸、视距和视角推导出的像素距离，只在这些前提下有对应意义。从距离进一步推断“该使用回弹”仍是经验判断。固定时长下距离与速度同时改变，单次对照难以区分二者的影响。对于由输入驱动的运动，还可改变速度或中途接管，分别看响应是否随输入改变、能否停住、是否额外占用下一次操作的时间。换设备、视距或输入方式时，分别核对几何换算、被代理的感知现象及实际操作结果。
