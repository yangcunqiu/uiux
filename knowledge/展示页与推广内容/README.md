# 展示页与推广内容

整页介绍一个产品与在功能页中插入推广，面对的是不同任务。前者要让访客理解价值、建立信任并找到下一步。后者先占用了使用者原本用来完成任务的空间。给内容专题的封面图起标题，又是内容展示本身。决定占多大面积、是否值得出现，要先辨明这三种用途。

## 展示页的顺序和布局

一种常见顺序是先让人知道产品做什么，再呈现用处、可信的证据和尝试入口。若实际访客更先关注可信度或适用对象，案例和限制条件就应提前。章节顺序可以由访客疑问检验。理论模型或成功网站的模块顺序，本身不能证明哪种排列能提高转化。

固定版心维护较轻，大屏会留出两侧空白。随宽度调整可以利用更多空间，需要为中间宽度设计布局。内容少、希望聚焦和逐屏揭示时，单屏切换能强化节奏，代价是妨碍快速滚动浏览。长页可以利用版形、色彩、区块明暗或关键动作让人辨认读到哪里。注册、试用、常规导航等必要操作宜保持容易识别。若探索本身就是作品目的，项目可重新权衡非常规导航的学习成本。

入口文案应描述实际下一步，例如“免费试用”与“联系销售”表示不同流程。初次行动要求填写的字段，应与这一阶段确实需要的信息相符。首屏好看与试用流程能否完成，可分别核对。

## 功能页内的推广

先检查推广是否挤走首屏内的主要功能，以及常驻内容会占用多少注意。顶部画面延伸至导航背后可以增强整体感，也会使导航文字的可读性依赖运营图片。齐屏但与导航分区可划清边界，独立卡片则保留功能页的版面边界。如果卡片背景与页面颜色过于接近，内容也可能失去视觉焦点。换用允许投放的最亮和最暗图片，核对返回、标题及其他必要操作。

内容流中，较安静的图文模块适合常驻和反复替换。鲜明的促销条适合短期、确实需要突出的一次活动。多处同时提高视觉强度会削弱优先级差异。推广是否值得占据某个位置、使用者是否会忽略它，要结合曝光频率与目标判断，不能只以“看起来更突出”代替实际效果。
