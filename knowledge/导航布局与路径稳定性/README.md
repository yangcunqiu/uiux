# 导航布局与路径稳定性

桌面一级导航放顶部、侧边或两处分层，取决于名称总宽度、层级深度、用户如何在模块间切换，以及内容区能让出多少空间。一级项少、名称短、层级浅时，顶部导航可以给表格留下更多宽度。名称长且需要经常深入二级时，侧栏的纵向增长更容易容纳内容。混合布局适合一级相对少且稳定、二级较多的情形，同时占用高度和宽度。

## 导航收起会改变什么

展开的侧栏能读名称与层级，却持续占用内容宽度。收成图标栏后，辨认更多依赖图标和熟悉程度，二级名称可能不可见。完全收进抽屉时，关闭状态下连有哪些版块也可能看不到。三种状态按保留的信息区分，实际宽度由文字、图标、内容和最小窗口决定。收起状态是否跨页保留会影响下一次进入时能否按熟悉位置操作。用户正在比较数据时，收起引发的列宽重排也有代价。需要整个视口显示内容时，可以另设明确的全屏方式。

二级项在一级项下面展开，会移动后续一级入口。手风琴一次只开一组，能节省高度，但切换时鼠标下方附近的位置可能改变。常驻展开保留层级，代价是总长与滚动。独立二级列可保住一级位置，适合深入同一模块，却多占一列宽度。依附一级项的浮层省宽，适合短时跨模块切换，需照顾缺少悬停的输入方式。不要用固定菜单项数推导航容量。相同数量的短标签与翻译后的长名称，可能分别占一行和数行。

## 入口改动与旧路径

分别检查位置、路径和命名。减少一次点击的收益有限，如果新路径要求用户猜测目标或重新寻找熟悉入口，实际成本可能更高。位置改变会影响熟悉的点击位置，路径改动会影响能否按旧层级找到目标，改名会影响搜索、同事指引和培训材料。把常用功能提升为附加入口，可以在保留原层级的同时减少操作。若移除原来的位置，则是结构迁移，还要检查路由、权限和当前位置提示是否同步。
