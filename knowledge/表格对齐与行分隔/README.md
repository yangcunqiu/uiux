# 表格对齐与行分隔

对齐要服务于这一列具体需要比较的部分。金额用同一单位和精度、数值能完整放下时，右对齐可以让相同数位靠近同一条竖线。混用“万元”和“元”、混用小数位数、或尾部已经截成省略号时，对齐边缘不能补救比较条件。数字字形宽度也会影响纵向对齐的精度。

统一的是字段类型与排法的对应关系。相同前提下，同一个表格字段跨页面应按同一约定对齐。金额、数量、比例等按位比较的值，在单位、精度一致且放得下时默认右对齐，即使其中一页主要用于读取单个数值。日期、名称、订单号等通常从共同起点阅读，格式统一有助于扫描。编号即使只含数字，也未必有大小比较的意义。枚举标签等宽时可以居中，长度差异大时左对齐更易沿起点查找。布尔值可在整列统一左对齐或居中，操作列则跟随按钮的位置。列标题默认跟随内容。这个判断针对成列数据，单张卡片中的价格或单个金额输入框需按各自任务处理。

## 给行还是给单元格加边界

相同行高、稳定留白且内容较短时，空白就能支持分行。副文本或换行导致行高变化后，等距线索减弱，可以用弱横线或交替底色维持行身份。逐格对读的报表、矩阵更可能需要网格线。主要识别每一行时，纵线和重边框会增加视觉干扰。底色与线都用于同一个分隔目的时，要注意叠加的强度。打印、深色主题或系统覆盖颜色时，重新检查剩余线索。

底色还可能表示悬停、选中、超限或分组。同一色系的明度差异可表达同类状态的程度，含义不同的状态可用不同色相、符号或文字区分，并为影响操作的状态提供其他标识。已使用交替底色时，要留出与悬停和选中区分的空间。单元格的突出色会打断整行边界，适用于该格本身就是需要识别的结果。分组行需要比普通行更明确的层级，表格中可用跨列标题或有区分的底色。

密度由字号、内容行高、上下留白和是否允许换行共同形成。紧凑能让同屏显示更多行，也可能减小操作目标或使说明难读。检查时同时使用长内容、不同状态、真实输入设备，分别验证能否辨认对象、比较目标字段、操作正确的行。
