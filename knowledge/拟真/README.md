# 拟真：一条规律，几条线索

"像不像"不是物理精度的比赛。用户读的是**预期的那条规律在不在**、**线索齐不齐**。两个例子分别对应这两个层次：越界回弹只有一条规律（拉出量和手指位移的关系），玻璃有几条线索（折射、色散、高光）。

## 先看演示

- [越界回弹](越界回弹.html)：同一个拖动输入，硬停、线性 ×0.35、渐近公式三种处理；带曲线图和"跟手率"读数。
- [玻璃与材质](玻璃与材质.html)：一块玻璃的折射、色散、高光可以逐个开关；另有透明玻璃、磨砂玻璃、染色塑料三种配方。

两个都是单文件，双击打开，不需要构建，不联网。页面上没有自动循环动画；系统开启"减少动态效果"时，越界回弹直接归位。

观察重点：

1. 越界演示里把输入推到 0.46d：两种公式的"跟手率"读数相同，但拉出量差了 50px 左右。
2. 推到 1.0d：两者的拉出量几乎一样。再往后线性反超——所谓"渐近公式更好"，差别不在这一段。
3. 玻璃演示里关掉高光：剩下的折射和色散还在，但玻璃立刻变成一块软塑料。
4. 切到磨砂或染色塑料：配方行里的折射归零或接近零——位移图在这两种材质上没有活干。

## 一、一条规律：越界回弹

### 手感来自跟手率在变化

先给"跟手率"一个定义：手指移动 1px，内容移动多少，也就是曲线在这一点的斜率 `dy/dx`。它和"阻力"反着走——跟手率越低，拉起来越费劲。

演示里 d 取这一栏的可视宽度（1400 窗口下 1332px），c=0.55。实测：

| 越界输入 x | 线性 ×0.35：拉出 / 跟手率 | 渐近公式：拉出 / 跟手率 |
|---|---|---|
| 0.25d | 117 / 0.35 | 161 / 0.43 |
| 0.46d | 214 / 0.35 | 269 / 0.35 |
| 1.00d | 466 / 0.35 | 473 / 0.23 |
| 1.50d | 699 / 0.35 | 602 / 0.17 |

三件事值得记：

- **跟手率在 0.46d 处相等**（都是 0.35）：之前渐近公式更跟手，之后更费劲。
- **拉出量在 1.0d 出头追平**：前面多给的，被后面少给的抵掉了。
- 再往后线性反超（1.5d：699 对 602）。

所以"线性公式手感不对"不能解释成"它更硬"或"它更软"——在一个屏幕的范围内它俩的总量几乎一样。差别是：**渐近公式的跟手率一路在降，线性的一直不变。**

### 常数替代不了曲线

渐近公式的跟手率从 0.55 降到 0.17，任何一个固定比例都只能对上其中一处。按相对误差把两头配平，最优常数约 **0.43**，在起点和 1d 处各差 **21%**。所以"调一调系数"追不上形状——这不是参数没调好，是少了一个维度。

### 上限不可感

渐近公式的上限是 d（拉出量永远不会超过一个屏宽）。但逼近得极慢：拉到 4d 才到 0.69d，7d 才到 0.79d，十几 d 才到 0.9d。日常操作到不了这个量级，**所以"有上限"是公式的性质，不是手感的原因。** 想让上限可感，只能把 d 换成更小的量（比如容器的一半），或者把 c 调大。

### 名字里有方向

这个量如果叫 `resistance`，每个实现的人都会读反：数值越大应该越难拉，但 0.55 比 0.35 更容易拉。它该叫 `follow`、`followRatio`，或者干脆在文档里写清"每 1px 手指，内容移动多少"。**参数的名字要和"数值变大意味着什么"对齐**，否则公式再准，接的人第一次也会用错。

## 二、几条线索：玻璃

### 玻璃感是边缘现象

三条线索都随"离边缘的距离"变化：

- **折射**：用一张**位移图**编码每个像素往哪挪。中心是中性灰（127,127,127），所以不位移；越靠边越饱和。红通道管左右，蓝通道管上下，强度 = scale/2 像素。
- **色散**：把 RGB 拆开，各自用略有差别的位移强度（演示里 32 / 28.8 / 25.6），再合回去。强度差决定彩边的宽度。
- **高光**：最外那 1.5px 的锥形渐变，用 `mask` 裁成边环，再用 `mix-blend-mode: overlay` 和底下的内容混合——所以它会跟着背景变亮变暗，而不是一条死白线。

中心干净、边缘忙，这是玻璃和"半透明色块"的分界。

### 线索有主次

关掉不同的线索，材质退化的方向不一样：

| 关掉 | 变成什么 | 像不像玻璃 |
|---|---|---|
| 高光 | 一块软塑料 / 亚克力 | 最不像——没有边界 |
| 色散 | 水、清水玻璃 | 还像玻璃，只是换了材质 |
| 折射 | 一圈空心壳 | 像一个描边，不像实体 |

所以"三条缺一不可"说得过头了。更准确的是：**线索要共享同一个场（都从边缘起算），但不必齐全；缺哪条决定了它退化成什么材质。**

## 三、材质是线索的组合

同一块面板，换配方就换材质：

| 材质 | 折射 | 色散 | 高光 | 模糊 | 染色 |
|---|---|---|---|---|---|
| 透明玻璃 | 强 | 有 | 锐 | 无 | 极淡 |
| 磨砂玻璃 | 弱 | 无 | 弱而柔 | 有 | 乳白 |
| 染色塑料 | 无 | 无 | 有 | 无 | 强 |

换材质要换的是线索组合，不是换一张图。**位移图只服务"折射"这一类**：同一个位移图改强度和边缘宽度，能得到玻璃球、水滴、放大镜；但磨砂靠散射，塑料靠染色和反射，方向图在那两件事上没有用。

顺带一条细分：高光不止一种。

- **轮廓光（rim）**：沿边缘的一圈亮线——玻璃的招牌。
- **反射条纹（specular）**：表面上的一道或几道反光——塑料、金属的招牌。

演示里只做了 rim，所以染色塑料看起来更像"亚克力板"而不是塑料件。这不是配色问题，是**少了一条线索**。

由此得到一条可操作的顺序：**不够像的时候，先数线索，再调参数。** 参数只能让一条线索更准，不能让缺失的线索出现。

## 为什么这样判断

- 越界的数字来自演示页的读数：跟手率 = 渐近公式的导数 `c / (1 + c·x/d)²`，拉出量按公式算。0.43 和 21% 是按相对误差配平的解，不是测量。
- "用户读的是跟手率在变化"是解释，不是测量。数字只证明形状不同；能不能感觉到，需要拖动验证——这次对照里有一个观察者能分辨，并偏好渐近公式。这是单人判断，不是普遍结论。
- 玻璃的三条线索和"缺哪条变成什么"来自逐个开关的对照观察；其中"关高光最不像"是这次讨论里一致的判断，样本很小，不是用户测试。
- 位移图、色散、高光的做法在 Chromium 里逐项验证过；其他浏览器的行为没有逐一验证。

## 适用条件和取舍

- **平台**：真实落地常用 `backdrop-filter: url(#filter)`，Safari 不支持引用 SVG 滤镜。演示用"复制一层背景 + 滤镜"绕开了这个限制，代价是玻璃只能在自己的舞台里移动。
- **性能**：滤镜在尺寸或位置变化时要重新光栅化；大面积的背景模糊 + 位移在低端设备上会掉帧。演示里舞台固定 920×520，就是为了控制这一点。
- **SVG 的模糊是整体的**：磨砂玻璃的"粗糙度从中心到边缘变化"在 SVG 里只能整体模糊加遮罩近似。要做渐变磨砂，得上 canvas 或 WebGL。
- **上限与量级**：参考实现里 c 常见取值 0.55–0.85，越小越紧；演示里的 0.55 是下限，不是推荐值。换容器尺寸要重新看 d。
- **减少动态效果**：越界回弹属于"跟随类"运动，对运动敏感的用户应该直接关掉回弹；玻璃没有动画，不受影响。
- **拟真不是物理模拟**：这整套判断的目标是"读起来对"，不是"算得对"。所以它适合表现层，不适合需要精确物理反馈的地方（比如仿真、工程预览）。

## 例子

- iOS 列表、图片查看器的越界回弹：位移上限不可感，真正起作用的是跟手率的变化。
- 控制中心、侧边栏的玻璃：三条线索齐全，但高光最不能省。
- 模态背景的磨砂：只有模糊和乳白，没有折射——它本来就不该被当成玻璃看，而是一层"遮挡"。
- 品牌色的塑料按钮：染色 + 表面反射条纹，不要加折射；加了就成了"彩色玻璃"。
