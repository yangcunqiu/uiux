# 窗口适配与断点过渡

视口是浏览器中可用于查看页面的区域。布局使用的 CSS 像素与显示器的物理像素是不同单位。窗口变宽时，普通文档按可用宽度重新排布。固定最大宽度的内容会增加两侧留白，元素不会仅因屏幕变宽而自动同比例变大。最小支持宽度应按使用者实际可用的视口确定，不能只看显示器分辨率。[CSS 的绝对长度单位](https://www.w3.org/TR/css-values-4/#absolute-lengths)

浏览器页面缩放和系统显示缩放可能改变可用于布局的 CSS 像素数。相同逻辑视口配更高密度的屏幕，可以主要体现为更细致的绘制。页面上的几何变换可改变绘制尺寸而保留原布局占位。移动设备上的捏合放大通常改变看得见的区域，也不能简单等同于改动布局宽度。

表格、表单和阅读界面缩窄时，优先调整布局、层级和可见内容。把整个设计稿按一个比例缩小，会连同文字和点击目标一起缩小。海报、游戏、固定画幅的数据展示可以选择整体缩放，须接受宽高比变化带来的留白或裁切，并核对是否还有需要阅读或操作的细节。

## 断点附近要观察什么

断点是布局在某个宽度改变规则的位置。列数、导航形式或信息显隐可以在断点切换。若新布局从区间窄端就使用按宽端设定的字号和间距，名称可能刚换行又恢复一行，或必要字段短暂被裁掉。只查看几张典型宽度的设计稿会漏掉中间的失败。调整实际窗口，核对换行、溢出、截断和关键操作的可达性，并考虑系统缩放取整后的边缘宽度。

同一布局内，若确实需要连续变化，可分别为字号、间距等属性确定窄端和宽端的可接受值，在两端之间插值并限制范围。例如在宽度 w₁、w₂ 上分别选定可接受值 v₁、v₂，区间内可用 v₁ + (v₂ − v₁) × (w − w₁) / (w₂ − w₁) 计算中间值。每个属性有自己的端点，区间外按相应布局处理。选择单位要能表达项目的校准依据，字号也要保留用户放大的能力。结构切换仍可使用离散断点。校准点增加后，每项属性都有新的维护成本，工具可以计算中间值，不能替项目决定端点。对内容容忍度较高或差异无可见后果的页面，少量分档就可能足够。
