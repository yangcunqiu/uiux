# 圆上的首尾

把一串有首尾的东西——一个词、一串色标——放到一个没有首尾的圆上，首尾相遇的地方必须有人处理。这个位置会以两种面目出现：文字里是**缺口**，渐变里是**硬边**。两件事看起来无关，处理的是同一个问题：圆没有起点，而我们的素材有。

## 先看演示

- [文字环绕](文字环绕.html)：同一段文字、同一个半径的三种排法（等角度 / 字宽 / 墨迹）。可以切「撑满整圆」，可以勾「描边跟着缺口断开」。
- [渐变接缝](渐变接缝.html)：同一条色带的三种补法（不补 / `from` 加 8 / `from` 减 8），下面是正圆和 `scaleX` 拉伸的椭圆。

两个都是单文件，双击打开，不需要构建，不联网。页面没有自动动画。

观察重点：

1. 切到「CHANELN°5」：等角度那一栏在 `°` 和 `.` 周围空出一大块，另外两栏不空。
2. 切到「中文」：三栏几乎一样——汉字的字宽本来就相同。
3. 勾「描边跟着缺口断开」：同一个缺口，描边完整时像少排了一个字，描边在同一处断开时像留了一个开口。
4. 渐变里第二、三个轮子都没有接缝，但只有第二个轮子的白线正指着 3 点刻度；第三个偏了 16°。

## 我们的理解

### 一、"均匀"要先说清等分的是什么

沿圆弧排字有三种常见做法，它们的区别不在算法，在**把什么量等分**：

| 排法 | 等分的是 | 保住什么 | 丢掉什么 |
|---|---|---|---|
| 等角度 | 每个字占同样的角度（360/n） | 天然闭合，不需要处理缺口 | 字宽差：窄字周围出洞，宽字挤到邻居身上 |
| 字宽 | 弧长，按字体给出的字宽 | 字体自带的字距节奏，词形还在 | 需要处理剩余弧长 |
| 墨迹 | 弧长，按笔画实际占的宽度 | 几何间隙相等 | 字体设计的侧距和词形节奏 |

演示默认那段 20 个字符的文本（半径 100、字距 8px），三种排法的空隙范围是 **26px / 8px / 0px**（空隙 = 槽宽 − 墨迹宽）。换成 `CHANELN°5`，是 **15px / 7px / 0px**。换成中文，三者都掉到 **2px 量级**。

所以「等角度会把空隙弄得不均匀」这句话是有条件的：它只发生在**字宽不齐**的文字里——拉丁小写、标点、数字混排。汉字、等宽字体、纯大写短串里，这个问题基本不存在；中文的环形字直接用等角度就可以，不必去测字宽。

### 二、读，还是看：一道门

整圈文字不是"读"的形式。一个词绕成圈，必然有一处断开；读完要绕一整圈；起读点也不明确。它适合被认形，不适合被快速读。

这不是一条连续的轴，而是一道门槛：

- **不是读**（徽章、印章、标识、装饰）：字距宽到什么程度都只是风格，缺口怎么消失都行。
- **是读**（品牌名、机构名、纪念文字）：字距是排版决定，不能让内容长度反推；缺口必须被"认领"。

分界线不是"重要不重要"，而是"要不要按顺序读完"。需要按顺序读完的东西——标题、按钮、金额——不该做成环，应该换形式。

### 三、缺口由谁认领

处理缺口有四条路，前三条是"认领"——让别的东西来承接它；最后一条是不认领。

| 出路 | 代价 | 前提 |
|---|---|---|
| 藏进字距（摊开 / 撑满整圆） | 字距由内容决定：字少就拉开，字多就挤紧，极端时词形散掉 | 这段文字不承担阅读 |
| 让别的元素在同一处断开 | 只改描边、边框或分隔线 | 环上有别的东西可以配合 |
| 缺口里放东西（年份、星、logo、起读点） | 缺口必须是信息位 | 有一段空弧可放 |
| 干脆不闭环，用一段弧 | 改形式 | 允许不成整圆 |

摊开这一条可以量：解出来的字距用 em 读。演示里默认那段文字撑满整圆解出 **0.25em**，和固定 0.2em 几乎看不出差别；把 `CHANELN°5`（9 个字）放到半径 100 的圆上撑满，解出 **1.10em**，字就散成一圈字母，不再是"一个词"。所以窄的那一头是"没有缺口但字距变宽"，宽的那一头是"词形没有了"。

反面最典型：**描边是完整的，缺口只在字里**。这时缺口没有主人，读者会读成"字没排满"或者渲染出错。同一个缺口，描边跟着断，它立刻变成"开口"。

所以缺口的处理不是"藏起来"或"摊开"，而是：**让它成为一个可读的断点，并让别的元素配合它。**

### 四、读的文字，能动的东西有顺序

字距不能动，就只能按代价从小到大改别的：

**字距（不动）→ 半径 → 字号 → 文案长度 → 不成环**

- 改半径：图形尺寸跟着变，版式要重排。
- 改字号：改变了信息层级，同一组徽章会不齐。
- 改文案：不是设计能定的，属于内容和产品的约定。
- 不成环：改形式，代价最大，但常常最正确。

这也是"内容预算"的来源：一个环形组件如果字距固定，它能容纳的字数就有一个窗口。超出窗口不是调参，是换方案。

### 五、渐变里的同一件事

渐变的首尾不叫缺口，叫硬边。CSS 的 `conic-gradient` 在 0/360 处不会自己插值：没有 360° 的色标时，它把最后一个色值钳到 360°，于是起点两侧颜色不同，出现一条笔直的接缝。

认领的方式是给首尾一个明确的色值：把首标钉到 0°，再在 360° 放同一个颜色。但这会把整条色带挪动 8°，所以 `from` 必须补回来——**`from` 要加 8，不是减 8**。减 8 等于让色带又退了一次，合起来偏 16°。

实测（canvas 的 `createConicGradient`，和 CSS 同一套停靠点模型）：

| 版本 | 0° 与 359.5° 的色差 | 与原始色带的最佳对位 |
|---|---|---|
| 直接导出 | 230/255 | — |
| 补 360，`from` 加 8 | 4/255 | 偏移 0°，误差 0 |
| 补 360，`from` 减 8 | 3/255 | 偏移 16°，误差 0.5 |

三栏里只有后两栏把接缝补掉了；这两栏之间，只有一栏和原来的色带对得上。

这就是两边共通的判断：**修掉看得见的坏，要拿看不见的参照去验。** 硬边消失之后，人就不再检查了，所以补端点时必须留一个"不动点"：

- 渐变：留一个尖锐的色标（演示里那根白线），或者把补完的图和原图叠着对位。
- 文字：字距和起读点——缺口藏起来之后，能证明"字还是那个词"的只剩这两样。

### 六、形状也是模型的一部分

`conic-gradient` 只能给出正圆的角向分布；设计工具里的角向渐变可以被压扁成椭圆。用 `scaleX` 拉伸能得到相同的像素布局，代价是元素上的**一切**都被拉宽——框、点、文字、阴影。

这不是精度问题，换算法也解决不了；它是两个工具的模型差异，只能用另一种变形去补。

同一条差异还解释了旋转：正圆上"转元素"和"转 `from`"是等价的；一旦形状被拉伸或者元素上还有别的内容，就不等价了——转元素会把椭圆本身转歪，转 `from` 只让光在走。所以形状是设计的一部分时转光源，整个东西要转（转盘、轮播）时转元素。

## 为什么这样判断

- 文字部分的数字是演示页的读数：空隙 = 槽宽 − 墨迹宽，墨迹宽取自 `canvas.measureText` 的 `actualBoundingBoxLeft/Right`。它是几何读数，不是用户测试。
- 三种排法的差别随文案变化（拉丁文明显、中文消失），这是同一页面内换文案得到的对照，不是跨人群的实验。
- 渐变部分的对位是采样算出来的：在 30°–330° 之间按 2° 采样，对每个候选旋转角算平均色差，取误差最小的那个角度。表格里的 0° 和 16° 是这个搜索结果。
- "读 / 看"这条判据来自我们自己的对照观察，没有外部研究支撑。它是一个工作假设：能解释为什么同一个缺口在不同场合该有不同的处理，但它不是定律。
- "整圈文字不是读的形式"是从它的几何推出来的（必有一处断、要绕一圈、起点不明），不是从偏好推出来的。

## 适用条件和取舍

- **字体是异步的**。字宽依赖实际加载的字体；字体没到时量到的是回退字体的宽度，加载完会重排。`ResizeObserver` 只能修"变了之后"，修不了"第一次就错"。徽章放在首屏会跳一下，值得单独处理。
- **这里把字当成一个宽度**。没有算字形轮廓（圆、方、尖）、字偶距和两侧留白，所以"墨迹最均匀"只在这个模型里成立；真正的视觉均匀还要再多一层。
- **一个字符一个槽的假设会被打破**：连字、组合字符、emoji 的零宽连接序列、全角半角混排，都会让"字数"和"槽数"对不上。
- **认领需要别的元素配合**。环上没有描边、没有可放的图形、也没有断点可留时，第三条路（不闭环）往往是唯一正确的。
- **渐变的补法是近似**。用一段从末色回到首色的过渡，代替设计工具真实的首尾插值；接缝附近的颜色和原件并不相同——演示里"补 360"的轮子在接缝带内本来就和"直接导出"不一样，这是有意的，不是误差。
- **`scaleX` 是拉伸不是椭圆渐变**。线宽会变粗或变细，文字和图标会变形；如果椭圆里要放内容，得反向缩放，而那又会带来新的模糊。
- **减少动态效果**：两个演示都没有自动动画，滑动和勾选都由用户触发。

## 例子

- 印章、徽章、标识环：看的形式。等角度或摊开都行；缺口交给描边的开口，或者干脆吃掉。
- 机构名、纪念文字绕成圈：读的形式但接受绕圈。字距固定，缺口留在接缝，并用断开的环或一个年份把它变成位置标记。
- 榜单页的光环：渐变。补端点时同时补 `from`，再用一个尖锐的色标核对光源位置。
- 表圈、纪念币：读和看并存。文字必须能被认出来，但没人会从头读到尾——这类最需要"断在明处"。
