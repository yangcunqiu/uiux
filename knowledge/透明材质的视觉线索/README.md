# 透明材质的视觉线索

界面若有意模拟玻璃、磨砂或染色塑料，可先确定哪些可见线索帮助人辨认材质，再调强度。不同线索改变的是不同现象，这套方法用于视觉表现，不能当作精确物理仿真的依据。

| 线索 | 能观察到的变化 |
|---|---|
| 折射 | 背景细节在材质边缘产生有方向的位移。中心较稳定、边缘位移较明显时，可以表现有厚度的透明边界。 |
| 色散 | 不同颜色通道有细微不同的位移，边缘出现彩边。减弱它仍可能读作清玻璃。 |
| 高光 | 轮廓上的亮边或表面的反射条纹给出边缘、光源和表面朝向的线索。 |
| 模糊与染色 | 背景细节被散开或整体带上颜色，分别可用于表现磨砂和染色材料。 |

一种透明玻璃表现可组合边缘折射、细微色散和较清楚的轮廓高光。磨砂玻璃更依赖模糊与柔和混色，染色塑料可以主要使用染色和表面反射。具体组合属于表现选择。只用一张位移图调整背景，能改变折射，不能自动补出缺少的高光或散射。若结果像有轮廓的透明空框，需要检查内部与边缘关系。若像亚克力板而非有曲面的塑料件，可以检查表面反射条纹。

这类判断受背景细节、光源和所在页面影响。界面上还有文字或可操作控件时，应单独核对清晰度、对比和性能。平台缺少某种滤镜时可以采用较便宜的表现，只要仍能辨认必要内容和前后层关系。视觉上是否足够像目标材质，由具体项目比较选择。
