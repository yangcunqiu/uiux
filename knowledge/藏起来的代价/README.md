# 藏起来的代价

把选项收进触发器，省的是版面，欠的是信息。欠的那部分不是"多点一次"，是关着的时候有些问题答不了。

## 先看演示

[留痕与跳档](留痕与跳档.html)（双击打开，不需要本地服务）

上半：一个「处理状态」下拉，两个问题——A 现在选的是哪个；B 一共还能选哪些。点开再关掉，看两个问题的答案怎么变。

下半：同一条筛选栏，五个条件已经生效（待审核、已超时、我负责的、今日到期、高优先级），切换六种"关着"的写法。

观察重点：

1. 上半：问题 A 一直能答（触发器上写着"处理中"）；问题 B 关着时答不了，点开才变成"能看到 4 个"。同一个控件，两件事的留痕不一样。
2. 下半：每种写法能说出几个名字——什么都没有：0；只剩数字：0（但知道有 5 个）；全部写出：5；截断一行：3（第四个只露半截）；写 3 个 + 2：3；写 3 个（不标）：3。
3. 截断和"不标"看起来像写全了。只有"全部写出"能五问五答。
4. 底部的表逐条标了"能说出 / 只露半截 / 看不见"，可以对着数。

## 我们的理解

**四类缺口。** 藏起来，用户可能缺四样东西：入口（有没有这个功能或选项）、集合（有哪些）、并置（能不能和别的东西一起比较）、状态（现在是什么）。点击成本排第五，而且最小。

**三问。** 判断一次藏贵不贵：

1. **能不能取回**？入口在不在、看不看得出来。
2. **要取几次**？一次就够 / 每次都要 / 必须并置（两样东西同时在场才比得出）。
3. **取错了会怎样**？慢一点 / 挑个次优 / 直接做错。

按这三问排，最贵的是取不回来的那一档：用户不知道自己缺了什么，界面也收不到信号——没有点击、没有报错、没有搜索。

**留痕四级。** 无痕 → 只有数量 → 有内容 → 全露。

同一个控件对不同问题可以停在不同级别。单选下拉是最清楚的例子：触发器写着当前值（状态是"有内容"），但集合是"无痕"（不打开就不知道还有哪些）。所以"这个下拉做得好不好"没有答案，要问"对哪个问题"。

**级别会跳档。** 不完整的痕迹有三档，危险程度不按信息量排，按"它有没有承认自己不完整"排：

- **明说不全**（"+2"、"还有 3 项"）：安全。它告诉你还缺，该取的时候会去取。
- **暗示不全**（省略号、渐隐、滚动条）：看信号强弱。省略号在长行末尾、字号又小，很容易被当成排版噪声。
- **不说**（只写前三个，没有任何标记）：最危险。它看上去就是全部，用户不会去取。

所以"截断一行"和"写 3 个不标"可能比"只剩数字"更差：数量版逼你打开，它们让你以为不用打开。

**假回执。** 两处数字不同步、摘要过期、角标没更新——它比无痕更贵。无痕会让人去查；假回执让人按错的前提行动。

**范围由位置和选中数承担。** 图标或文字负责说"做什么"；"对谁"由位置（行内、工具栏、页头）和选中状态说。一个图标猜不出范围，不是图标画得不好，是位置没交代清楚。

## 为什么这样判断

- "取不回来"是唯一用户无法自救的一类：他不会去查自己不知道存在的东西。
- 数量不是内容：数量回答"几个"，不回答"哪些"；需要核对时，只有名字有用。
- 截断和三档信号是推论；演示里能验证的是"关着时屏幕上有什么"——能读出几个名字是数出来的，不是估的。
- 上述四级和三问是模型，不是标准。本文把它当作讨论和设计的脚手架，不当作被测过的结论。
- 演示是结构对照，不是用户测试：没有测反应时间，也不能证明哪种写法转化更好。

## 适用条件和取舍

- **只对"任务真的需要"的信息成立。** 不需要的信息，藏起来是省地方，不是代价。先问"用户需不需要知道"，再问"留没留痕"。
- **频率修正。** 单次损失不等于总损失。高频控件（筛选）里，每次多取一下会累积；低频功能（导出）里，一次没找到就是全部。
- **规模修正。** 选项多到用户不愿意取（或者不知道自己要找什么），"不知道有哪些"就退化成"不知道有"——他不是没找着，是不找了。
- **四级不是越高越好。** 升到"有内容"要占地方、要维护同步；只在需要核对时才值得升。不需要核对时，数量版更省。
- 选择控件本身的语义（互斥、集合、半选）在[承诺与边界](../承诺与边界/README.md)；弹层的位置与尺寸在[边界上的弹层](../边界上的弹层/README.md)。本文不重复这些。

## 例子

- **筛选栏**：只写"筛选 5"能答数量，答不了是哪五个；条件 chips 能答内容，代价是占一行。
- **单选下拉**：触发器写了当前值（状态有痕），集合仍要打开才知道。
- **命令菜单**：图标连"有几个"都答不了；"更多操作 5"能答数量；摊开才能答内容。

- "+N" 的上限、点击后展开还是弹层，没有统一做法。
- 读屏怎么读 chips 和"已选 N 项"，还没有展开。
